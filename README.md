# Оновлення Femida meetily

Це публічне сховище містить лише підписані файли автоматичних оновлень для
застосунку **Femida meetily**. Вихідний код застосунку зберігається окремо у
приватному репозиторії.

- Сторінка оновлень: <https://fem10da.github.io/femida-meetily-updates/>
- Маніфест оновлень: <https://fem10da.github.io/femida-meetily-updates/latest.json>

Файли публікуються автоматично після успішної збірки macOS і Windows та
перевірки підписів Tauri.
